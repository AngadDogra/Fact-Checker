# Celebrity Gossip Credibility Classifier

## Project Overview
This project focuses on predicting the credibility of celebrity gossip using machine learning classification techniques. By leveraging Logistic Regression and Random Forest Classifiers, we aim to distinguish between true and false claims in celebrity-related news from Gossip Cop and political sources.

## Dataset
- **Source**: Gossip Cop and Political News Datasets
- **Features**: Extracted text and metadata related to celebrity gossip
- **Target Variable**: Binary label (True/False)
